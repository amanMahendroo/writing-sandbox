# Master Tag Registry

## Skill Focus (`skill/`)
- `skill/sensory`  : Environmental details, textures, acoustics, atmosphere.
- `skill/dialogue` : Character interaction, subtext, verbal pacing.
- `skill/pacing`   : Action, tension, scene transitions.

## Emotional Tone (`tone/`)
- `tone/conflict`  : Disagreement, confrontation, hostility.
- `tone/anxiety`   : Internal dread, uncertainty, hesitation.
- `tone/wonder`    : Exploration, awe, unfamiliarity.

## Asset Potential (`asset/`)
- `asset/location`  : Buildings, geography, indoor settings.
- `asset/artifact`  : Tools, relics, documents, objects.
- `asset/character` : Personas, quirks, motivations.
